## Open-source tools

- **[next-bilingual-rtl-starter](https://github.com/faisalidris014/next-bilingual-rtl-starter)**: Minimal Next.js starter for English (LTR) and Arabic (RTL) websites with `hreflang` wiring, clean typography, and accessible language switching.
- **[small-biz-ai-assistant-kit](https://github.com/faisalidris014/small-biz-ai-assistant-kit)**: Zero-dependency Node.js reference architecture for a hardened small-business AI website assistant with HMAC-signed conversation state, deterministic pricing/safety guards, sliding-window rate limits, spend-cap circuit breakers, and an adversarial eval harness.
- **[ai-seo-readiness-check](https://github.com/faisalidris014/ai-seo-readiness-check)**: Lightweight CLI that audits a website or local HTML file for traditional SEO basics and AI search readiness (crawlers, structured data, `llms.txt`, and server-rendered content).
